# Planetarium

A Firefox/Gecko-based browser experiment focused on spatial navigation, living UI, constellations, motion, and heavy front-end customization.

## Prime Directive

Gecko is the engine.
Planetarium is the experience.

Do not modify browser-engine/backend behavior unless a proven Planetarium requirement cannot be achieved through Firefox's existing frontend/platform capabilities.

## First Light

Planetarium 0.001 has one goal:

Build Firefox from source, launch it, and make one unmistakable visible Planetarium modification.

## Design Language

- The Web is the center.
- Browser capabilities orbit around attention.
- Bookmarks become Stars.
- Groups of Stars become Constellations.
- History can exist as a living Starfield.
- Motion communicates state.
- UI recedes when it is not needed.
- Themes may alter the physical frame of the browser, not merely page colors.
- Conventional controls remain available when precision is more useful than novelty.

## Architecture Rule

If a subsystem cannot be explained on one architecture map, it is not ready to be abstracted further.
